# GA 내부 시연 PoC 준비 기록 (2026-09-27)

## 1차 시연 범위

1차 범위는 사용자가 선택한 합성 고객 데이터 기반 GA 설계사 내부 시연이다. /insurance의 고객·보험사·상품은 가상 샘플이다. 실제 고객 조회나 보험 판매는 시연 목표에 넣지 않는다.

약관 자료실에는 KB손해보험 질병보험 공시 PDF 50건, 추출 텍스트 9,315페이지, 키워드 기반 후보 문구 941건이 있다. 941개 문구는 표시된 TXT 페이지와 문자열이 일치한다. 조항의 법률적 해석이나 개별 계약의 지급조건으로 검증한 것은 아니다. 50건 모두 한 보험사 자료이므로 GA의 다보험사 상품 비교를 대표하지 않는다.

## 시연 동선과 합격 기준

1. /insurance에서 합성 계약 상태, 수집 누락, 예비 보장 신호를 본다. 상품명 신호를 실제 가입 담보로 확정하지 않는다.
2. /insurance/terms에서 공식 문서의 적용일과 수집 당시 판매 상태를 확인하고, 면책·감액·대기기간 후보 문구를 찾는다.
3. 후보 문구의 PDF 쪽수 링크로 해당 문서의 페이지를 열어 TXT와 대조한다. 목록에 없는 문서 요청은 404를 반환한다.
4. 비교 표는 같은 보험사의 약관 문구 탐색에만 쓴다. 보험료·수수료·실제 가입조건이 없어 판매용 비교설명서로 출력하지 않는다.

시연 합격 기준은 이 동선을 설계사가 끊김 없이 수행하고, 원문 페이지 오류·잘못된 인용·합성 데이터 오인이 없는 것이다.

## 실제 고객 데이터를 쓰는 GA 파일럿 이전 조건

| 영역 | 필요한 확인 |
| --- | --- |
| 기관·사용자 | GA 조직별 인증, 설계사 권한, 고객별 접근 제한, 퇴사자 차단, 조회·수정·출력 감사 기록 |
| 고객 정보 | 수집 목적·항목·보유기간·제3자 제공 범위의 동의, 건강정보의 별도 처리 근거, 철회·삭제 절차 |
| 계약 데이터 | CODEF 자격증명 교체와 운영 승인, 보험사별 특약·가입금액·상태 누락률 검증 |
| 약관 정확도 | 가입 시점 보험사·상품·특약·개정 버전 연결, PDF 원문 검수, 불일치 시 설계사 검토 대기 |
| 판매 설명 | 동일·유사 상품의 다보험사 자료, 보험료·수수료 정보, GA 준법 검토 및 설명 확인 절차 |
| 운영 | 공식 문서 수집 권한·갱신 주기, 장애 모니터링, 접근·보관·삭제 정책, GA 담당자 시나리오 검수 |

현 단계는 위 조건을 충족했다고 주장하지 않는다. 브라우저 저장 정보와 전화번호·생년월일 파생 키는 GA 사용자 인증 수단이 아니다. 50건을 추가 LLM으로 재분석하기 전에는 문서 버전 연결과 설계사 검수 기준부터 확정한다.
