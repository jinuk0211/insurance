# EACL Industry working manuscript — pilot V5

The current source is main.tex; the reviewed PDF is
[pilot V5](../output/pdf/fin-harness-eacl-industry-pilot-v5-draft.pdf).
See [verification](V5_MANUSCRIPT_VERIFICATION.md) for hashes and layout checks.
Main text: 6 pages. Including limitations, references and preserved appendices:
12 pages. All original eight tables and three figures are retained, with two
additional measured-result tables.

Build from the repository root with Tectonic 0.17.0:

    tectonic EACL_industry/main.tex

The supplied ACL style, bibliography and PNG assets are required. A fresh build
may need to download TeX dependencies; the recorded build used a local cache.
Do not treat unverified historical appendix numbers as current results.
This is a working manuscript, not a completed full-model study or a claim that
EACL acceptance requirements have been met.
